📘 Learn C – Interactive Learning Platform (Academic Project)
This project was developed during my BSc studies as an academic assignment.
It is an interactive learning platform designed to help students learn the C programming language through structured chapters, quizzes, and progress tracking.

🎯 Project Overview
The platform allows students to:
- Sign up / log in
- Read C programming chapters (variables, loops, functions, pointers, etc.)
- Attempt quizzes after completing each chapter
- View their progress
- See contest numbers / performance summary at the end of the final page
The goal was to create a simple e‑learning system focused on programming fundamentals.

🧠 Features
- User authentication (sign‑up & login)
- Chapter‑wise learning content
- Multiple‑choice quizzes
- Automatic scoring
- Progress tracking dashboard
- Contest number / performance summary
- Clean and simple UI for beginners

🛠 Technologies Used

- C# programming (core content)
- HTML / CSS
- PHP
- MySQL (user data & quiz results)
- Bootstrap (UI styling)
